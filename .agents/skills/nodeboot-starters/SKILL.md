# Node-Boot Starters

> No repo yet? Decide simple-repo vs. monorepo first — see
> [`../nodeboot-project-type/SKILL.md`](../nodeboot-project-type/SKILL.md).

Open the concrete skill that matches the starter being added; this orchestrator stays intentionally short so agents only load the one starter they need.

| Starter package                 | Use when                                                                                                                                                                                                                                                | Open next                                                                              |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `@nodeboot/starter-actuator`    | The user wants `/actuator/*` health, readiness, metrics, Prometheus, or k8s probe endpoints.                                                                                                                                                            | [`../nodeboot-starter-actuator/SKILL.md`](../nodeboot-starter-actuator/SKILL.md)       |
| `@nodeboot/starter-aws`         | The user wants AWS SDK clients (S3, SQS, SNS, DynamoDB, Secrets Manager) auto-configured from app config.                                                                                                                                               | [`../nodeboot-starter-aws/SKILL.md`](../nodeboot-starter-aws/SKILL.md)                 |
| `@nodeboot/starter-backstage`   | The user wants a Backstage catalog client or plugin discovery inside a Node-Boot service.                                                                                                                                                               | [`../nodeboot-starter-backstage/SKILL.md`](../nodeboot-starter-backstage/SKILL.md)     |
| `@nodeboot/starter-firebase`    | The user wants Firebase Admin beans such as auth, Firestore, storage, messaging, or realtime database.                                                                                                                                                  | [`../nodeboot-starter-firebase/SKILL.md`](../nodeboot-starter-firebase/SKILL.md)       |
| `@nodeboot/starter-http`        | The user wants outbound HTTP clients declared with decorators, not an inbound HTTP server adapter.                                                                                                                                                      | [`../nodeboot-starter-http/SKILL.md`](../nodeboot-starter-http/SKILL.md)               |
| `@nodeboot/starter-openai`      | The user wants an injectable OpenAI-compatible client configured from `app-config.yaml`.                                                                                                                                                                | [`../nodeboot-starter-openai/SKILL.md`](../nodeboot-starter-openai/SKILL.md)           |
| `@nodeboot/starter-openapi`     | The user wants generated OpenAPI docs or Swagger UI for existing controllers and models.                                                                                                                                                                | [`../nodeboot-starter-openapi/SKILL.md`](../nodeboot-starter-openapi/SKILL.md)         |
| `@nodeboot/starter-persistence` | The user wants TypeORM repositories, datasource wiring, transactions, or pagination helpers. Routes further to a SQL (`nodeboot-starter-persistence-sql`) or MongoDB (`nodeboot-starter-persistence-mongodb`) flavour skill once the database is known. | [`../nodeboot-starter-persistence/SKILL.md`](../nodeboot-starter-persistence/SKILL.md) |
| `@nodeboot/starter-scheduler`   | The user wants cron-like background jobs using `@Scheduler(...)`.                                                                                                                                                                                       | [`../nodeboot-starter-scheduler/SKILL.md`](../nodeboot-starter-scheduler/SKILL.md)     |
| `@nodeboot/starter-supabase`    | The user wants an injectable Supabase client for auth, database, or storage calls.                                                                                                                                                                      | [`../nodeboot-starter-supabase/SKILL.md`](../nodeboot-starter-supabase/SKILL.md)       |
| `@nodeboot/starter-validation`  | The user wants request DTO validation with `class-validator`.                                                                                                                                                                                           | [`../nodeboot-starter-validation/SKILL.md`](../nodeboot-starter-validation/SKILL.md)   |

For adding a skill for a new starter package, follow [`resources/authoring-a-starter-skill.md`](resources/authoring-a-starter-skill.md).
